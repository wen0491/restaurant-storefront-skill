# 验收与迭代规则

用原始输出观察招牌；必要时放大查看局部。文件存在、尺寸正确或提示词写了要求，都不构成视觉通过证据。

## A. 硬约束逐项核对

| 检查项 | 可观察证据 | 判定要点 |
|---|---|---|
| 招牌文字 | 逐字转录实际可见文字，与需求原文并列 | 错字、漏字、多字、顺序错、额外品牌文字均失败；不可辨认记无法判断 |
| 入口 | 位置、门洞数量、通向入口的可见路径 | 数量与左右位置准确；入口未被陈设、墙体或人群遮住 |
| 门窗 | 从左到右列出 D/W 编号、门扇与玻璃分格 | 按需求定义数门洞、窗洞；不能用分格数代替窗洞数 |
| 现状约束 | 对照原图的柱、梁、台阶、边界、邻铺及保留物 | 每条锁定项分别判断；照片遮挡或无依据的项保留未知 |
| 画幅与取景 | 实际像素宽高、比例、门头完整性 | 区分目标比例和实际比例；未达精确要求则失败；不得称插值放大为原生高分辨率 |
| 用户禁用项 | 按需求逐项检查 | 如禁止外摆、禁止红色或禁止改柱位，明确对应可见位置 |
| 复制店区域与材质（适用时） | 本店各区域与品牌档案逐条对照 | 替换材质正确、边界准确、保留元素未改变，没有影响区域外表面；无对应区域时不得自行新增 |

状态仅用：通过／不通过／无法判断／不适用。不适用必须有理由，不能用于规避未达成的要求。

硬约束汇总规则：有不通过 → 不通过；无不通过但有无法判断 → 待核验；适用项全部通过 → 自检通过。没有现状时不能给出“现场保真通过”。

## B. 审美检查

每项写“符合／部分符合／不符合／待用户判断”，并附具体画面依据，避免仅写“高级、好看”。

- 业态与品牌：能否读出预期餐饮类型和定位，是否被无关风格抢走。
- 立面比例：招牌、开口、柱面及留白的关系是否协调，门头是否压迫入口。
- 信息层级：主招牌是否清晰，辅助信息是否抢主次，文字是否贴边拥挤。
- 材料可信度：纹理尺度、接缝、反射、转角是否合理，有无融化、漂浮或材质混杂。
- 色彩与灯光：是否符合案例方向，冷暖关系和亮度是否可读。
- 参考响应：是否落实指定的参考特征，是否误借了结构或品牌。
- 街道关系：招牌、外摆和陈设的视觉尺度是否合理；不据此宣称审批、通行或消防合规。

助理自检与用户审美反馈分别存储。风格不符合已明确要求时，案例仍未通过；只有主观喜好尚待用户反馈时，可以标注“自检通过，待用户确认”。

## C. 修改优先级和停止条件

先处理几何/现状偏离、错误文字及入口问题，再处理风格和细节。一次编辑集中解决同一类问题；多个独立问题可按影响排序分轮解决。每轮都重查 A，已通过项也可能回退。

文字连续失真：缩短为用户允许的内容、集中局部编辑；未获准时不删改店名。若仍不稳定，记录“需后期排字”，不得把待排字图当成完整通过。只有用户要求或允许时，才另走确定性排字流程并重新验收。

几何连续漂移：保留最接近版本并记录失败；建议补充清晰正面照片或尺寸草图。默认初稿加两轮修订后停止，回报具体差异，不自行扩大生成次数。

## D. 证据强度

1. 文件结构校验：仅证明技能包可读、链接与格式有效。
2. 流程推演：未调用生图，仅证明本次对给定输入采用了什么处理。
3. 真实生图自检：必须有输出图片、实际提示词和看图记录。
4. 用户确认：记录用户原话及对应版本，不能由代理推断。

对外只使用达到的证据层级。单个案例不证明通用成功率、客户满意度或效率提升。
